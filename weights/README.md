# Backbone initialization weights

Run `python download_weights.py` from the repository root to obtain the filenames expected by the configuration:

- `wide_resnet50_2-95faca4d.pth`
- `vit_b_16-c867db91.pth`

These are ImageNet backbone weights, not full trained Spec-ResAD detector checkpoints. A checkpoint generated by `train.py`, containing learned constraintor/flow parameters, is needed by `test.py`. Pretrained weights and their originating software/data remain subject to their original terms.
